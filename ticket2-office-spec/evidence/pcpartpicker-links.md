# PCPartPicker Compatibility & Power Verification

> **Note on currency:** PCPartPicker does not list prices in Kazakhstani Tenge (KZT) or local Kazakhstan retailers. These four build lists are used strictly to verify **hardware compatibility** (CPU socket, DDR4 memory support, M.2 NVMe slot, GPU clearance) and **estimated total wattage** against each selected power supply. All KZT prices are documented separately in [`../budget.csv`](../budget.csv) and [`vendor-quotes/`](vendor-quotes/).

- **Build 1 — Accountant:** https://pcpartpicker.com/list/pYBHn2 — Verified LGA1700 + DDR4 + M.2 compatibility and estimated load against the 450W PSU.
- **Build 2 — Sales Manager:** https://pcpartpicker.com/list/BhC9R4 — Verified AM4 + DDR4 + M.2 compatibility and ~174W estimated load against the 450W PSU (note PCPartPicker's BIOS/compatibility warning for Ryzen 5000G on A520 boards).
- **Build 3 — Web Developer:** https://pcpartpicker.com/list/kZhZqd — Verified LGA1700 + DDR4 + M.2 + Micro-ATX form-factor compatibility and estimated load against the 450W PSU.
- **Build 4 — Designer:** https://pcpartpicker.com/list/knhrw3 — Verified LGA1700 + DDR4 + M.2 compatibility, RTX 3060 12GB clearance inside the Lian Li A3-mATX case, and estimated load against the 600W PSU.
